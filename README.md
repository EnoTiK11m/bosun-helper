# Bosun Helper

Расширение для Chrome и других Chromium-браузеров, которое упрощает работу с
алертами в Bosun и помогает безопасно переносить запросы в Grafana.

Bosun Helper уменьшает визуальный шум на дашборде, добавляет быстрые действия и
уведомляет о новых Needs Acknowledgement. Расширение не отправляет
Ack/Note/Close самостоятельно: окончательное действие всегда остаётся за
пользователем.

## Возможности

- скрытие silenced-алертов и всей секции **Acknowledged**;
- фильтр Needs Ack без активного пользовательского комментария;
- понятные обозначения алертов с Note и без Note;
- кнопки **Копировать** и **Копировать все** с очисткой служебного текста, отдельное копирование текста последней заметки без автора и времени и кликабельные HTTP(S)-ссылки в заметках;
- шаблоны частых комментариев на странице `/action`;
- автоматическое снятие флага `Notify` в локальной форме `/action`;
- настраиваемое автообновление главной страницы после бездействия;
- звуковые и постоянные визуальные уведомления о новых Needs Ack, которые
  исчезают после появления Note;
- отсутствие повторного звука при работе в нескольких вкладках;
- предварительный просмотр PromQL перед передачей в Grafana;
- выбор между **Вставить** и **Вставить и выполнить**;
- автоматическое удаление просроченных запросов Grafana.

Если открыто несколько вкладок Bosun, `/api/alerts` опрашивает только одна из
них. Остальные получают актуальный снимок через `BroadcastChannel`, что снижает
лишнюю нагрузку на Bosun. Активная вкладка проверяет алерты примерно раз в
4 секунды, фоновая — раз в 10 секунд.

## Требования

- Google Chrome, Chromium или Microsoft Edge с поддержкой Manifest V3;
- доступ к настроенным HTTPS-адресам Bosun и Grafana;
- Node.js 20 или новее — только для настройки и разработки;
- Node.js 22 рекомендуется для browser-тестов и используется в CI.

Внешних runtime-зависимостей нет: расширение работает без сборщика и без
`node_modules`.

## Установка из исходников

1. Скачайте или клонируйте репозиторий.
2. При необходимости настройте адреса по инструкции ниже.
3. Откройте `chrome://extensions/`.
4. Включите **Режим разработчика**.
5. Нажмите **Загрузить распакованное расширение**.
6. Выберите директорию, в которой находится `manifest.json`.
7. Обновите открытые вкладки Bosun и Grafana.

После изменения исходников нажмите **Обновить** на карточке расширения и
перезагрузите целевые страницы.

## Настройка адресов

Рабочая конфигурация хранится в `config.js`, а разрешённые страницы — в
`manifest.json`. Эти файлы должны оставаться синхронизированными.

Для изменения адресов создайте локальную конфигурацию:

```powershell
Copy-Item config.example.js config.local.js
```

Для Bash:

```bash
cp config.example.js config.local.js
```

Заполните `config.local.js`:

```js
globalThis.BosunHelperLocalConfig = {
  bosunHosts: ['bosun.example.com', 'bosun-test.example.com'],
  grafanaHost: 'grafana.example.com',
  grafanaPanelUrl: 'https://grafana.example.com/d/example/dashboard?editPanel=1'
};
```

Затем синхронизируйте конфигурацию:

```bash
npm run sync-config
```

Скрипт проверяет формат hosts, обязательный HTTPS для Grafana и совпадение
`grafanaHost` с URL. После выполнения проверьте изменения в `config.js` и
`manifest.json`.

`config.local.js` добавлен в `.gitignore` и не должен попадать в коммиты.
Порты можно указывать в hosts, например `grafana.example.com:8443`.

## Использование

### Bosun

Откройте главную страницу Bosun. Панель управления появится над дашбордом и
позволит управлять фильтрами, уведомлениями и автообновлением.

На странице `/action` расширение добавляет шаблоны комментариев. Оно изменяет
только локальную форму и никогда не нажимает кнопку отправки.

### Grafana

Нажмите **Grafana** возле алерта. Перед открытием панели расширение покажет
полный запрос:

- **Отмена** — ничего не открывать;
- **Вставить** — заполнить редактор без запуска;
- **Вставить и выполнить** — заполнить редактор и нажать Run queries.

Всегда проверяйте запрос и выбранный диапазон времени перед выполнением.

## Конфиденциальность и безопасность

- запрашивается только разрешение браузера `storage`;
- content scripts запускаются только на hosts из `manifest.json`;
- полные снимки `/api/alerts` не сохраняются в `localStorage` или
  `chrome.storage`;
- между вкладками они передаются только временно через `BroadcastChannel`;
- выбранный PromQL хранится в `chrome.storage` только до открытия Grafana или
  истечения TTL;
- ID и severity новых алертов временно хранятся в `chrome.storage`, пока алерт
  находится в Needs Ack без Note;
- запросы Grafana имеют уникальный request ID и ограниченный срок хранения;
- результат page bridge дополнительно проверяется по содержимому редактора;
- пользователь явно выбирает, нужно ли выполнять запрос;
- внешние значения вставляются в интерфейс как текст, а не как HTML;
- расширение не отправляет действия Ack, Note или Close автоматически.

## Разработка

Основные команды:

| Команда | Назначение |
| --- | --- |
| `npm test` | Smoke, integration и regression-тесты |
| `npm run test:browser` | DOM-тесты в реальном Chrome/Chromium/Edge |
| `npm run check` | Тесты, синтаксис JavaScript и структура manifest |
| `npm run sync-config` | Синхронизация локальной конфигурации |

Для browser-тестов путь к браузеру можно указать явно:

```powershell
$env:BOSUN_HELPER_BROWSER = 'C:\Program Files\Google\Chrome\Application\chrome.exe'
npm run test:browser
```

В Linux переменная задаётся так:

```bash
BOSUN_HELPER_BROWSER=/usr/bin/google-chrome npm run test:browser
```

CI запускает `npm test`, `npm run test:browser` и `npm run check` для каждого
push и pull request.

## Проверка изменений перед коммитом

```bash
npm test
npm run test:browser
npm run check
git diff --check
```

Не добавляйте в коммит `config.local.js`, локальные профили браузера, временные
файлы и персональные настройки среды разработки.

## Устранение неполадок

### Панель не появилась в Bosun

- проверьте, что адрес страницы присутствует в `manifest.json` и `config.js`;
- перезагрузите расширение на `chrome://extensions/`;
- обновите вкладку Bosun после перезагрузки расширения.

### Grafana не открывается

- разрешите всплывающие окна для Bosun;
- проверьте `grafanaHost` и `grafanaPanelUrl`;
- убедитесь, что URL использует HTTPS и содержит `editPanel`.

### Browser-тест не находит Chrome

Установите Chrome/Chromium/Edge или задайте путь через
`BOSUN_HELPER_BROWSER`.
