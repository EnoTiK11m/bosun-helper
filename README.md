# Bosun Helper

**Удобнее разбирать алерты в Bosun и переносить PromQL в Grafana.**

Расширение для Chromium-браузеров на Manifest V3. Добавляет инструменты прямо на страницы Bosun и помогает открыть проверенный запрос в настроенной панели Grafana.

> Ack, Note и Close отправляет пользователь. Расширение не выполняет эти действия самостоятельно. Если данные алерта или редактор нельзя однозначно определить, дополнительное действие не предлагается либо отменяется.

## Основные возможности

| Возможность | Что даёт |
| --- | --- |
| Возраст одиночного алерта | Показывает возраст вместо количества у однозначно распознанной одиночной группы в Needs Acknowledgement и Acknowledged. |
| Note и Priority | Отмечает наличие активного Note; выделяет приоритетные алерты по настраиваемому списку точных имён. Priority не определяется одной лишь severity. |
| Компактный Acknowledged | Позволяет скрыть обычные алерты, сохранив приоритетные. Отдельный фильтр управляет отображением Silenced. |
| Копирование и выделение | Копирует Subject, текст раскрытых детей и Last Action; помогает выделять текст и выбирать checkbox без случайного раскрытия группы. |
| Шаблоны действий | Отдельные редактируемые шаблоны для Note, Ack и Close. Текст вставляется в форму, отправка остаётся за пользователем. |
| Новые алерты | Показывает счётчики новых Needs Ack на странице и подаёт звуковые сигналы с учётом severity. |
| Автообновление | Перезагружает главную страницу после бездействия; откладывает reload при вводе, выделении текста или скрытой вкладке. |
| Grafana | Показывает preview PromQL, переносит запрос в редактор и, по явному выбору пользователя, выполняет Run queries после проверки вставки. |

## Где работает

Доступ ограничивается адресами, заданными при настройке. Требуются доступ к сервисам и действующая пользовательская сессия.

| Страница | Возможности |
| --- | --- |
| Главная Bosun, путь `/` | Панель настроек, отображение алертов, Priority, фильтры, копирование, уведомления, обновление и действия Grafana. |
| Bosun `/action?type=…` | Шаблоны для `note`, `ack`, `close`. При обнаружении новой формы исходно включённый Notify снимается; его можно включить вручную перед отправкой. |
| Настроенная edit-панель Grafana | Приём запроса, открытого через Bosun Helper. Само посещение Grafana ничего не запускает. |

Код рассчитан на Angular-разметку Bosun и поддерживаемые редакторы CodeMirror/Monaco в Grafana. Поддержка произвольных версий и изменённых интерфейсов не гарантируется.

## Установка и настройка

Нужны Chrome, Edge или совместимый Chromium-браузер с Manifest V3, а для команд проекта — Node.js и npm. Рекомендуется **Node.js 22+**: браузерным тестам необходим глобальный WebSocket. Дополнительных npm-зависимостей и сборщика нет.

1. Скачайте исходники и распакуйте их либо клонируйте репозиторий. Команды ниже выполняются из корня проекта.
2. Скопируйте [config.example.js](config.example.js) в `config.local.js`. Если локальный файл уже существует, сохраните его настройки.
3. Укажите адреса своего окружения:

   | Поле | Значение |
   | --- | --- |
   | `bosunHosts` | Массив разрешённых имён hosts Bosun, без схемы и пути. |
   | `grafanaHost` | Host Grafana, без схемы и пути. |
   | `grafanaPanelUrl` | Полный HTTPS-адрес целевой панели в режиме редактирования, с `editPanel` и нужными параметрами dashboard. Host должен совпадать с `grafanaHost`. |

   Домены из примера — заглушки. Пароли и токены в URL не указывайте; авторизация выполняется в браузере.
4. Синхронизируйте конфигурацию:

   ```sh
   npm run sync-config
   ```

   Команда обновит `config.js` и адреса в `manifest.json`. Ручное редактирование только одного из этих файлов не заменяет синхронизацию.
5. Откройте `chrome://extensions` или `edge://extensions`, включите режим разработчика и выберите **«Загрузить распакованное расширение»**. Укажите корень проекта с `manifest.json`.
6. Перезагрузите вкладки Bosun и Grafana. На главной Bosun откройте настройки расширения и проверьте нужные функции.

После смены адресов повторите `sync-config`, обновите расширение на странице управления расширениями и перезагрузите вкладки.

### Повседневная работа

- В настройках можно включать функции, редактировать список Priority и шаблоны, задавать интервал автообновления. Для новой установки большинство функций включено; интервал бездействия — 60 секунд. Изменение обработки Last Action требует перезагрузки страницы.
- Для переноса запроса нажмите Grafana у алерта, проверьте preview и выберите вставку либо вставку с выполнением. Проверьте datasource и временной диапазон целевой панели.
- Для первого звукового сигнала браузеру может потребоваться клик или нажатие клавиши на странице. Визуальные уведомления находятся внутри Bosun, а не в системном центре уведомлений.

## Разработка и проверки

Исходники — обычный JavaScript без сборки: [src/bosun](src/bosun) содержит интеграцию Bosun, [src/grafana](src/grafana) — обработку запросов и перенос, [src/settings](src/settings) — настройки, [src/shared](src/shared) — общие механизмы. Порядок загрузки задаёт [manifest.json](manifest.json).

| Команда | Назначение |
| --- | --- |
| `npm test` | Node-тесты конфигурации, упаковки, настроек, запросов, интеграции и регрессий. |
| `npm run test:browser` | Синтетические DOM, Angular и editor-сценарии в настоящем Chromium. Нужен установленный браузер; путь можно задать через `BOSUN_HELPER_BROWSER`. |
| `npm run check` | Проверка manifest, ресурсов, порядка загрузки, синтаксиса JavaScript и части тестов. |
| `npm run sync-config` | Генерация рабочей конфигурации из `config.local.js`. |
| `npm run status` | Краткий Git status, версия, доступные локальные задачи и записанные результаты проверок. Сам тесты не запускает. |
| `npm run hooks:install` | Установка локальных проверок перед commit и push с сохранением существующих hooks. |
| `npm run check:publish` | Проверка содержимого текущего Git index без публикации. |
| `npm run check:history` | Аудит доступной локальной истории и refs; не подтверждает состав удалённого репозитория. |
| `npm run package:internal` | ZIP настроенного расширения в `dist/`, только с runtime-ресурсами и лицензией. Требует настоящей конфигурации вместо заглушек. |

Основной набор проверок:

```sh
npm test
npm run test:browser
npm run check
```

Дополнительно: `npm run test:promql-engine -- <путь-к-promtool>` проверяет выражения настоящим Prometheus engine. Команды `npm run check:docs` и `npm run verify` предназначены для рабочего окружения с локальными Roadmap, CHANGELOG и worklogs; эти документы не поставляются в публичном репозитории.

### Конфигурация и публикация

`config.local.js` и `dist/` исключены из Git, но **`config.js` и `manifest.json` отслеживаются**. После `sync-config` они содержат адреса вашего окружения: проверяйте содержимое изменений перед публикацией. Внутренний ZIP также содержит настроенные адреса и не предназначен для открытого распространения.

Для подготовки публичных конфигураций предусмотрена `npm run prepare-commit`: она перезаписывает рабочие `config.js` и `manifest.json` значениями из `config.example.js`, проверяет публичный вариант и ничего не добавляет в index. Не запускайте её, если нужно сохранить текущие локальные значения в этих файлах. После публикации рабочую конфигурацию можно восстановить из сохранённого `config.local.js` командой `npm run sync-config`.

Git-защита проверяет содержимое index и исходящих commits/tags; найденные значения не печатает. Подготовленное удаление старого запрещённого документа допускается, его повторное добавление — нет. Hooks устанавливаются локально и не заменяют ручную проверку или защиту на сервере.

## Ограничения и особенности

- При неоднозначном соответствии группы, алерта или редактора расширение сохраняет штатное отображение либо отказывается от действия. Отсутствующий возраст или кнопка Grafana не обязательно означают ошибку установки.
- «Копировать все» работает с детьми группы, уже находящимися в DOM. Сначала раскройте группу; отдельного запроса полного списка нет.
- Фильтр «Без комментария» сейчас выключен. Компактный Acknowledged зависит от включённого Priority; «Показать все» не отменяет отдельный Silenced-фильтр.
- Выключение автообновления страницы не выключает получение данных об алертах: polling координируется между вкладками отдельно.
- Grafana-перенос поддерживает ограниченный набор выражений Bosun, а не произвольные графики. Временной диапазон и datasource Grafana автоматически не подстраиваются под Bosun; корректный запрос может вернуть пустой результат или ошибку backend.
- Смена панели, несколько редакторов, истечение времени ожидания или ручное редактирование могут отменить вставку либо Run. После успешной вставки и отменённого Run текст может остаться в редакторе.
- Настройки хранятся локально и синхронизируются между открытыми вкладками. При ошибке хранилища изменения могут действовать лишь до перезагрузки. Полный snapshot алертов не сохраняется в постоянное хранилище.
- Браузерные тесты используют синтетические страницы. Совместимость с конкретной установкой Bosun/Grafana нужно проверять отдельно.
