# Bosun Helper

Chrome/Chromium-расширение для дашборда Bosun. Оно уменьшает визуальный шум,
помогает разбирать Needs Acknowledgement и открывает запрос алерта в Grafana.

Расширение читает `/api/alerts`, изменяет только отображение страницы и не
отправляет Ack/Note/Close в Bosun. На странице `/action` оно снимает флаг
`Notify` в локальной форме; окончательное действие по-прежнему выполняет
пользователь.

## Возможности

- скрытие silenced alerts в секции **Acknowledged**;
- отдельная кнопка полного скрытия секции **Acknowledged**;
- фильтр Needs Ack без активного пользовательского комментария;
- метка **Silenced** у muted-алертов;
- обозначение алертов с Note и без Note;
- кнопки **Copy** и **Copy all**;
- очистка копируемого текста от служебных элементов;
- автообновление главной страницы после настраиваемого периода бездействия;
- звуковые уведомления о новых warning/critical Needs Ack без дублирования
  между вкладками;
- открытие конкретного запроса алерта в отдельной вкладке Grafana;
- шаблоны частых комментариев на странице `/action`;
- автоматическое снятие checkbox `Notify` на странице `/action`.

Выключенное автообновление остаётся выключенным после перезагрузки. Настройки
синхронизируются между открытыми вкладками расширения.

## Поддерживаемые адреса

Точный список находится в `manifest.json` и должен совпадать с `config.js`.
Текущая production-конфигурация включает:

- `https://bosun.example.com/*`;
- `https://bosun-test.example.com/*`;
- `https://grafana.example.com/*`.

`config.local.js` игнорируется Git и служит исходником локальной конфигурации.
Он не загружается браузером напрямую.

Чтобы сменить адреса:

1. Скопируйте `config.example.js` в `config.local.js`.
2. Заполните Bosun hosts, Grafana host и HTTPS URL панели.
3. Выполните `npm run sync-config`.
4. Проверьте изменения в `config.js` и `manifest.json`.

Скрипт валидирует адреса и обновляет оба файла одновременно.

## Установка

1. Откройте `chrome://extensions/`.
2. Включите **Developer mode**.
3. Нажмите **Load unpacked**.
4. Выберите директорию проекта с `manifest.json`.
5. Обновите вкладки Bosun и Grafana.

После изменения исходников нажмите **Reload** у расширения и обновите страницы.

## Разработка

Требуется Node.js 20 или новее. Внешних runtime-зависимостей нет.

```bash
npm test
npm run check
```

`npm test` запускает unit/smoke-проверки доменной логики. `npm run check`
дополнительно проверяет синтаксис всех JavaScript-файлов и структуру manifest.

Ключевые модули:

- `alerts-data.js` — нормализация Note и индекс алертов;
- `needack-baseline.js` / `needack-severity.js` — обнаружение новых алертов;
- `promql.js` — безопасное добавление alert tags в PromQL;
- `sound.js` — воспроизведение и межвкладочная дедупликация;
- `activity.js` — активность пользователя и автообновление;
- `grafana-page.js` — изолированный bridge к редактору Grafana;
- `grafana-content.js` — получение адресованного запроса и управление bridge;
- `content.js` — координация UI и жизненного цикла.

## Безопасность

- расширение запрашивает только разрешение `storage`;
- content scripts ограничены перечисленными HTTPS hosts;
- аудиофайлы доступны только Bosun, а page bridge — только Grafana;
- bridge использует случайный channel token;
- запросы Grafana имеют уникальный request ID и автоматически протухают;
- данные алертов не вставляются в DOM через `innerHTML`.
