# История изменений Bosun Helper

## 2.0.0 — 2026-10-12

### Улучшена работа Priority

Исправлено отображение Priority у нескольких экземпляров одного алерта,
покрытых одним точным правилом. Выделение группы сохраняется при раскрытии
и сворачивании, когда её соответствие текущим данным подтверждено.
Кнопка управления точным правилом остаётся внутри конкретного алерта.

### Улучшено отображение Note

Повышена устойчивость индикаторов Note при повторной отрисовке и замене
элементов страницы. Групповые индикаторы используют подтверждённое состояние
алертов; неоднозначные соответствия по-прежнему отклоняются.

### Ускорена первоначальная загрузка индикаторов

После загрузки настроек первые свежие данные Bosun могут использоваться для
отображения Note и Priority без ожидания выбора ведущей вкладки. Это не создаёт
дополнительных запросов и не запускает уведомления или другие действия владельца
обновления. Время появления зависит от доступности данных и готовности страницы.

### Повышена стабильность идентификации алертов

Улучшена обработка допустимых имён тегов и внутренних ASCII-пробелов в их
значениях. Для свёрнутых групп добавлено чтение полного состава алертов из модели
страницы без её изменения. Сохраняются проверка актуальности данных,
уникальности идентичностей и разделение Needs Acknowledgement / Acknowledged.
Конфликты и неоднозначные данные отклоняются без угадывания.

### Подготовлена внутренняя ZIP-сборка

Добавлена команда `npm run package:internal`, создающая архив только с
runtime-файлами расширения и MIT-лицензией. Проверяются конфигурация, необходимые
ресурсы и признаки credentials. Внутренняя сборка распространяется отдельно
через корпоративную Wiki и не прикладывается к публичному GitHub Release.

### Совместимость и обновление

Техническая версия: **2.0.0**, тег: `v2.0.0`. Расширение использует Manifest V3.
Изменение схемы настроек и миграция пользовательских правил не требуются.
Ack, Note и Close по-прежнему выполняются только пользователем.

При обновлении внутренней сборки замените содержимое прежней папки расширения,
сохранив её путь, обновите расширение на `chrome://extensions` и перезагрузите
страницы Bosun/Grafana. Подробности: [инструкция установки и обновления](docs/WIKI-INSTALL.md).
Для установки из публичных исходников требуется локально настроить адреса сервисов.
