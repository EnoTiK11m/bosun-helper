# Bosun Helper: установка из внутренней Wiki

Доступна новая версия Bosun Helper 2.0.

Улучшено отображение Priority и Note, ускорена первоначальная загрузка индикаторов
и повышена стабильность работы с алертами.

Для установки или обновления скачайте актуальный ZIP-архив с этой страницы:
`bosun-helper-internal-v2.0.0.zip` (техническая версия **2.0.0**).

## Установка

1. Скачайте ZIP Bosun Helper с этой Wiki.
2. Распакуйте архив в постоянное место, например в папку `BosunHelper`.
3. Откройте `chrome://extensions` и включите **Режим разработчика**.
4. Нажмите **Загрузить распакованное расширение**.
5. Выберите вложенную папку `bosun-helper`, содержащую `manifest.json`.
6. Перезагрузите открытые страницы Bosun и Grafana.

Адреса корпоративных сервисов уже настроены. Редактировать файлы и устанавливать
Node.js не нужно. Доступ к сервисам и вход в Bosun/Grafana остаются необходимыми.
Настройки расширения доступны на странице Bosun.

Не перемещайте установленную папку: Chrome загружает расширение из неё.
Если корпоративная политика запрещает распакованные расширения, обратитесь к
администратору браузера.

## Обновление

1. Скачайте новый ZIP с Wiki и распакуйте его во временное место.
2. На `chrome://extensions` временно выключите Bosun Helper.
3. Замените содержимое прежней папки `bosun-helper` содержимым новой одноимённой
   папки. Путь установленной папки должен остаться прежним; не вкладывайте новую
   папку внутрь старой. Старые файлы расширения предварительно удалите из этой
   папки, чтобы не оставить файлы предыдущей версии.
4. Включите Bosun Helper и нажмите **Обновить** (значок перезагрузки) на его карточке.
5. Перезагрузите страницы Bosun и Grafana.

Повторно нажимать **Загрузить распакованное расширение** не требуется.
При сохранении пути и профиля Chrome настройки расширения сохраняются.

## Удаление

На `chrome://extensions` найдите Bosun Helper и нажмите **Удалить**.
После удаления можно удалить его распакованную папку. Локальные настройки
расширения будут удалены; состояние алертов в Bosun не меняется.
